커스텀 테마 라이트 모드

iOS 전용 아이폰 카카오톡 사용자 테마

1카카오톡으로 보내기

파일로 직접 내려받기

공유 시트가 열리면 카카오톡 → 나와의 채팅을 고르세요. 나에게 보내 두면 언제든 다시 적용할 수 있습니다.

2채팅방에서 적용하기

  1. 보낸 custom_light.ktheme 파일을 탭합니다.
  2. 안내창에서 테마 적용하기를 누릅니다.
  3. 카카오톡이 다시 시작되면 적용 완료입니다.
버튼이 안 뜨거나 파일이 열리지 않아요
  1. 사용자 테마 허용이 꺼져 있으면 적용 버튼이 나오지 않습니다.
    카카오톡 더보기 ⋯ → 설정 ⚙︎ → 테마 → 사용자 테마를 켜 주세요.
  2. Android·PC 카카오톡에서는 적용되지 않습니다. iOS 카카오톡 전용 형식이라 아이폰(또는 아이패드) 앱에서 열어야 합니다.
  3. 파일을 다운로드 앱이나 파일 앱을 거쳐 열면 확장자가 .zip으로 바뀌는 경우가 있습니다. 이때는 채팅방에 공유해서 바로 탭하는 방법을 쓰세요.
  4. 카카오톡 버전이 낮으면 인식하지 못할 수 있습니다. 최신 버전으로 업데이트하세요.
원래 테마로 되돌리려면

카카오톡 더보기 ⋯ → 설정 ⚙︎ → 테마에서 기본 테마를 선택하면 됩니다.
