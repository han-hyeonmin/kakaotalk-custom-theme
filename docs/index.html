카카오톡 사용자 테마 v26.9.3

튜닝의 끝은 순정. 카카오톡 채팅방의 익숙한 느낌은 그대로 두고, 인스타그램의 하얀 화면과 군더더기 없는 기본 프로필 인상만 옮겨 왔습니다.

1카카오톡으로 보내기

파일로 직접 내려받기

공유 시트가 열리면 카카오톡 → 나에게를 고르세요. 나에게 보내 두면 언제든 다시 적용할 수 있습니다.

2채팅방에서 적용하기

  1. 보낸 custom-light.ktheme 파일을 탭합니다.
  2. 안내창에서 테마 적용하기를 누릅니다.
  3. 카카오톡이 다시 시작되면 적용 완료입니다.
버튼이 안 뜨거나 파일이 열리지 않아요
  1. 이 .ktheme 파일은 Android·PC 카카오톡에서 적용되지 않습니다. iOS 전용 형식이라 아이폰(또는 아이패드) 앱에서 열어야 합니다. 안드로이드는 별도 APK 소스를 빌드해야 합니다.
  2. 파일을 다운로드 앱이나 파일 앱을 거쳐 열면 확장자가 .zip으로 바뀌는 경우가 있습니다. 이때는 채팅방에 공유해서 바로 탭하는 방법을 쓰세요.
  3. 카카오톡 버전이 낮으면 인식하지 못할 수 있습니다. 최신 버전으로 업데이트하세요.
원래 테마로 되돌리려면

카카오톡 더보기 ⋯ → 설정 ⚙︎ → 테마에서 기본 테마를 선택하면 됩니다.

!안드로이드는 직접 빌드해야 합니다

안드로이드 카카오톡 테마는 APK(앱) 형식이라, 아이폰처럼 파일 하나를 공유해서 바로 적용할 수 없습니다. 소스는 공개돼 있으니 직접 빌드해 주세요.

안드로이드 소스와 빌드 방법 보기

JDK 21과 Android SDK 35가 필요합니다. 카카오 공식 샘플 테마를 받아 apply.sh를 돌리고 ./gradlew assembleDebug 하면 APK 가 나옵니다.

왜 바로 받을 수 있게 해두지 않았나요

APK 를 배포하려면 받는 쪽에서 「알 수 없는 출처의 앱 설치」를 허용해야 하고, 브라우저도 APK 다운로드에 경고를 띄웁니다. 개인이 만든 테마를 그렇게까지 해서 설치하시라고 권하기엔 부담이 커서, 소스만 공개하고 빌드는 각자에게 맡겼습니다.

iOS 판은 .ktheme 가 앱이 아니라 카카오톡이 읽는 설정 파일이라 이런 문제가 없습니다.

데스크톱에서 보고 계십니다. 아이폰이라면 이 페이지를 사파리로 열어 주세요. 안드로이드는 테마가 APK 형식이라 소스를 직접 빌드해야 합니다.

이미지 저작권 안내

테마에 포함된 기본 프로필 이미지(profileImg01@3x.png)는 출처와 저작권자가 확인되지 않은 파일입니다. 저작권 상태를 확인할 수 없는 상태임을 밝히며, 권리자이시거나 출처를 아시는 분은 이슈로 알려 주시면 즉시 교체하거나 삭제하겠습니다.

테마 썸네일 이미지는 직접 제작했으며, CSS·빌드 스크립트는 MIT 라이선스입니다. 카카오톡은 주식회사 카카오의 상표이고 이 테마는 카카오와 무관한 개인 제작물입니다.
