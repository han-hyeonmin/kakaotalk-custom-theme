# 심플 라이트 — 안드로이드

> **소스만 공개합니다. APK 는 직접 빌드해야 합니다.**
> iOS 는 `.ktheme` 파일 하나를 카카오톡에 공유하면 끝이지만, 안드로이드 카카오톡 테마는
> **APK(안드로이드 앱)** 형식이라 배포·설치 경로가 완전히 다릅니다.

## iOS 판과 무엇이 다른가

|  | iOS | Android |
|---|---|---|
| 배포 형식 | `.ktheme` (확장자만 바꾼 zip) | `.apk` (Gradle 로 빌드) |
| 색 정의 | `KakaoTalkTheme.css` | `theme/values/colors.xml` |
| 알파 | 별도 `-alpha` 키 | `#aarrggbb` 로 직접 |
| 밀도 | `@2x` / `@3x` | drawable 폴더 6종 |
| 설치 | 카톡 공유 → 탭 → 적용 | APK 설치(알 수 없는 출처 허용) → 앱 실행 → 적용 |

**가장 큰 차이는 "기본값에 맡기기"가 안 된다는 점입니다.** iOS 판은 네 곳만 선언하고
나머지를 카카오톡 기본값에 맡기지만, 안드로이드는 `theme-adv/` 의 셀렉터들이
`@color/...` 로 색 이름을 참조하기 때문에 **44개를 하나도 빠짐없이 지정**해야 합니다.
하나라도 없으면 빌드가 깨집니다. 그래서 `colors.xml` 은 무채색 6단 팔레트로
전체를 채웁니다.

## 빌드

### 필요한 것

- **JDK 21**
- **Android SDK** — Platform 35, Build-Tools 35.0.0
- 카카오 공식 안드로이드 샘플 테마 (`apeach-<버전>-source.zip`)
  카카오 고객센터에서 **"내가 직접 테마를 만들 수도 있나요?"** 로 검색하면 받을 수 있습니다.

이 저장소는 카카오가 제공한 샘플 소스를 재배포하지 않습니다. 샘플은 직접 받아 주세요.

### 절차

```bash
unzip apeach-26.7.0-source.zip -d /경로/apeach-26.7.0   # 1. 샘플 압축 해제
./apply.sh /경로/apeach-26.7.0                          # 2. 심플 라이트 얹기
cd build/simple-light && ./gradlew assembleDebug        # 3. 빌드
```

결과물은 `build/simple-light/build/outputs/apk/debug/` 에 생깁니다.
`assembleDebug` 는 표준 디버그 키스토어를 자동으로 만들어 서명하므로
별도의 키나 비밀번호가 필요하지 않습니다. 카카오 공식 샘플도 debug APK 로 배포됩니다.

### 설치

APK 를 기기로 옮겨 설치한 뒤(「알 수 없는 출처」 허용 필요), 설치된 **심플 라이트** 앱을
실행하고 **「테마 적용하기」** 를 누르면 카카오톡 테마 설정으로 넘어갑니다.

## `apply.sh` 가 하는 일

원본 샘플은 건드리지 않고 `build/simple-light/` 에 사본을 만든 뒤 그 위에서 작업합니다.

1. **색과 이름 교체** — `colors.xml`, `strings.xml`(한/영). 일본어 이름은 제거.
2. **배경·말풍선 이미지 제거** — 가이드의 *"이미지와 컬러가 동일하게 사용되는 요소는
   이미지 우선"* 규칙을 뒤집어 쓴 것입니다. 이미지를 없애면 `colors.xml` 의 단색이
   드러나고, 색조차 없는 요소(말풍선·잠금 불릿)는 카카오톡 기본값으로 떨어집니다.
   메인 배경은 `theme-adv/drawable/theme_background_image.xml` 이
   `<solid android:color="@color/theme_background_color"/>` 라 자동으로 이어받습니다.
3. **어피치 캐릭터 아트워크 제거** — 탭 아이콘 16종과 친구추가 버튼 2종.
   무채색으로 다시 칠하는 방법은 쓰지 않았습니다. 이 아이콘들은 단색 글리프가 아니라
   분홍·흰색·검정 외곽선이 섞인 캐릭터 일러스트라서, 알파만 살려 칠하면 디테일이
   뭉개진 실루엣 덩어리가 됩니다. 아예 빼고 카카오톡 기본 아이콘에 맡깁니다 —
   iOS 판이 탭 아이콘을 선언하지 않는 것과 같은 선택입니다.
   PNG 만 지우면 `theme-adv/` 의 셀렉터가 사라진 드로어블을 참조해 빌드가 깨지므로
   셀렉터 XML 도 함께 지웁니다. 이 셀렉터들을 참조하는 곳은 프로젝트 안에 없습니다
   (카카오톡이 런타임에 이름으로 찾습니다).
4. **기본 프로필 이미지** — iOS 판과 같은 파일을 씁니다.
5. **스플래시 단색 교체** — `make-splash.py`. 아래 참고.
6. **깨진 드로어블 참조 검사** — `@drawable/...` 참조를 전부 훑어 실제 파일이 있는지
   확인합니다. 하나라도 없으면 빌드 전에 멈춥니다.

## 스플래시만 예외인 이유

`theme_splash_image` 는 **지울 수 없는 유일한 자산**입니다.
`res/layout/main_activity.xml` 이 `android:src` 로 직접 참조하기 때문에 없으면
빌드가 깨집니다. 그래서 `make-splash.py` 가 밀도별 원본 해상도를 그대로 읽어
`#FFFFFF` 단색 PNG 로 덮어씁니다 (6장).

이 화면은 카카오톡 UI 가 아니라 **테마 앱 자신의 실행 화면**입니다.
설치 후 앱을 열면 「테마 적용하기」 버튼과 함께 잠깐 보이고 끝납니다.

`make-splash.py` 는 Pillow 을 쓰지 않습니다 — 단색 한 장에 의존성을 더할 이유가 없어
`zlib` 로 PNG 를 직접 씁니다. (`tools/make-icon.py` 는 연속 곡률을 그려야 해서 Pillow 이 필요합니다.)

## 팔레트

`theme/values/colors.xml` 의 44색은 모두 아래 6단에서 나옵니다. iOS 판과 같은 램프입니다.

| 값 | 역할 |
|---|---|
| `#FFFFFF` | 기본 배경 — 메인·탭바·헤더·잠금화면·스플래시, 인풋바·배너 |
| `#F7F7F7` | 살짝 가라앉은 면 — 잠금 키패드 |
| `#F2F2F2` | 가라앉은 면 — 채팅방, 프레스 배경 |
| `#DBDBDB` | 보더 |
| `#262626` | 주 텍스트 — 헤더, 버튼, 키패드 숫자 |
| `#666666` | 리스트 이름 |
| `#8E8E93` | 보조 텍스트 — 라스트메시지, 상태메시지 |
| `#8A8A8A` / `#B0B0B5` | 각 프레스 |

텍스트 값은 iOS 판(`KakaoTalkTheme.css`)과 같습니다. 리스트 이름이 `#666666` 인 이유는
[KEYMAP.md](../KEYMAP.md) 를 보세요 — 이 값이 더보기탭 그리드 타일 배경과 한 키로
묶여 있어 WCAG AA 한계선에서 절충한 결과입니다.

## 아직 확인되지 않은 것

**실제 기기에서 검증하지 않았습니다.** 아래는 가이드와 샘플 구조에서 읽어낸 것이라
빌드해 보신 뒤 확인이 필요합니다.

- 탭 아이콘·말풍선·잠금 불릿을 **빼면 카카오톡 기본값으로 떨어지는지.**
  가이드의 "이미지 우선" 규칙과 iOS 판이 생략으로 동작하는 방식에 비춰 그럴 것으로
  보지만, 명시된 문장은 없습니다.
- `theme_chatroom_background_color` 값. iOS 판은 채팅방을 손대지 않지만 안드로이드는
  값을 비울 수 없어 `#F2F2F2` 로 골랐습니다. 말풍선 9-patch 를 넣지 않으므로
  카카오톡 기본 말풍선(노랑/흰색)이 그 위에 얹힌다는 전제입니다.
